### Tool 1: search_listings
`search_listings(description: str, size: str, max_price: float) -> list[dict]`
**What it does:**
Filters the mock `listings.json` dataset for items matching the description (via substring match in title/description/tags), exact size, and a price less than or equal to `max_price`.


**Input parameters:**
<!-- List each parameter, its type, and what it represents -->
- `description` (str): Keywords for the item (e.g., "vintage graphic tee").
- `size` (str): The exact size string (e.g., "M").
- `max_price` (float): The upper limit for the price.

**What it returns:**
<!-- Describe the return value — what fields does a result contain? -->
A list of dictionaries representing matching listings. Each dict contains `id`, `title`, `description`, `size`, `price`, `brand`, and `platform`.

**What happens if it fails or returns nothing:**
<!-- What should the agent do if no listings match? -->
If no matches are found, it returns an empty list `[]`. The agent must intercept this and ask the user to adjust their criteria.

### Tool 2: suggest_outfit
suggest_outfit(new_item: dict, wardrobe: list[dict]) -> str

**What it does:**
<!-- Describe what this tool does in 1–2 sentences -->
Takes the newly found item and compares it against the user's existing wardrobe to generate practical styling advice.

**Input parameters:**
<!-- List each parameter, its type, and what it represents -->
- `new_item` (dict): The selected item dictionary from `search_listings`.
- `wardrobe` (dict): The user's current wardrobe items (loaded via `get_example_wardrobe()` or `get_empty_wardrobe()`).

**What it returns:**
<!-- Describe the return value -->
A string containing 1-2 sentences of styling advice.

**What happens if it fails or returns nothing:**
<!-- What should the agent do if the wardrobe is empty or no outfit can be suggested? -->
If the wardrobe is empty, it returns a generalized styling suggestion using common basics (e.g., "Pair this with standard blue jeans or neutral trousers").

---

### Tool 3: create_fit_card
create_fit_card(outfit: str, new_item: dict) -> str 
**What it does:**
<!-- Describe what this tool does in 1–2 sentences -->
Summarizes the item and outfit into a short, punchy caption suitable for social media.

**Input parameters:**
<!-- List each parameter, its type, and what it represents -->
- `outfit` (str): The styling advice generated by `suggest_outfit`
- `new_item` (dict): The selected item dictionary

**What it returns:**
<!-- Describe the return value -->
A short string formatted like an Instagram caption with emojis.

**What happens if it fails or returns nothing:**
<!-- What should the agent do if the outfit data is incomplete? -->
If the LLM generation fails or times out, the tool returns a hardcoded fallback string: *"Just thrifted this [title]! Ready to style it up. #ThriftScore"*

## Planning Loop

**How does your agent decide which tool to call next?**
<!-- Describe the logic your planning loop uses. What does it look at? What conditions change its behavior? How does it know when it's done? -->
The agent will operate using a conditional sequential loop driven by state checks.
1. **Initialize State:** Create a `session_state` dict: `{"selected_item": None, "outfit_suggestion": None, "fit_card": None, "error": None}`.
2. **Execute Search:** Extract parameters from the user query and call `search_listings`.
3. **Condition 1 (Search Result):** 
   * If `results` is empty: Set `session_state["error"] = "No items found."` and return an early response to the user asking them to raise their budget or change the description. Halt execution.
   * If `results` has items: Set `session_state["selected_item"] = results[0]` and proceed.
4. **Execute Outfit Suggestion:** Call `suggest_outfit` using `session_state["selected_item"]` and the loaded wardrobe. Set `session_state["outfit_suggestion"] = result`.
5. **Execute Fit Card:** Call `create_fit_card` using `session_state["outfit_suggestion"]` and `session_state["selected_item"]`. Set `session_state["fit_card"] = result`.
6. **Final Output:** Format the data from `session_state` into a single, cohesive response to the user.

## A Complete Interaction (Step by Step)

Write out what a full user interaction looks like from start to finish — tool call by tool call. Use a specific example query.

**Example user query:** "I'm looking for a vintage graphic tee under $30. I mostly wear baggy jeans and chunky sneakers. What's out there and how would I style it?"


**What FitFindr Does:**
FitFindr is an AI agent that parses a user's natural language request for secondhand clothing, triggering a search tool to find matches in a mock database, and sequentially passes those results to an outfit suggester and a social-media caption generator. If a step fails, such as the search tool returning zero matches, the agent immediately halts the tool chain, informs the user of the failure, and requests modified search criteria rather than passing empty data to the next tool.

**Trace Example:**
* **User Query:** "I'm looking for a vintage graphic tee under $30, size M. I mostly wear baggy jeans and chunky sneakers."
     * **Step 1:** The agent calls `search_listings(description="vintage graphic tee", size="M", max_price=30.0)`. It finds a match (e.g., a $22 Faded Band Tee) and holds it in the session state.
     * **Step 2:** The agent calls `suggest_outfit(new_item=<band tee>, wardrobe=<user's wardrobe>)`. It returns styling advice based on the user's baggy jeans and chunky sneakers. 
     * **Step 3:** The agent calls `create_fit_card(outfit=<suggestion>, new_item=<band tee>)` to generate a short, shareable text snippet summarizing the thrifted find and the outfit.
     **Final output to user:** 
     Based on the example trace, the final output would look something like this:"I found a great match for you! I tracked down a Faded Band Tee in size M for $22 on Depop.
     How to style it:
     Pair this with your wide-leg jeans and platform Docs for a classic 90s grunge look. Roll the sleeves once and tuck the front corner slightly for shape.
     Your Fit Card:
     thrifted this faded band tee off depop for $22 and honestly it was made for my wide-legs 🖤 full look in my stories"
